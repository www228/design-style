# 设计风格

面向海报、PPT与演示文稿的 Codex Skill，内置15种视觉风格，根据受众、场景、内容与展示媒介推荐，也支持用户自主选择。

## 使用

调用标识为 `$design-style`，显示名称为“设计风格”。

- 自动推荐：用设计风格，帮我做一张面向小学生的AI课程招生海报。
- 指定风格：用设计风格的第8种山海机关科创风做一套PPT。
- 自己选择：列出设计风格菜单，我自己选。
- 仅要方案：推荐一个适合家长课程汇报的风格，先给设计说明。

用户已选风格时直接采用；未选择时给出一个首选，按需提供备选。海报与PPT分别适配布局、信息密度与可读性。实际制作使用当前环境中可用的图片生成、演示文稿或排版工具。

## 风格库

探索家日志、深网赛博极客、史诗魔幻策略、前沿流体玻璃、星际探索学院、超级英雄训练营、赛博城市安全局、山海机关科创、像素冒险闯关、未来产品发布会、儿童AI乐园、机甲工程实验室、梦境发明家工坊、极地科考安全站、校园未来研究所。

完整编号、场景索引和执行规则见 [SKILL.md](SKILL.md)，详细视觉设定见 [references/](references/)。

## 文件与安装

将 `SKILL.md`、`agents/`、`references/` 放入本地 `~/.codex/skills/design-style/` 目录。

[设计风格.skill](dist/设计风格.skill) 是包含同一套Skill文件的ZIP格式便携包，可解压获得 `design-style/` 文件夹。
