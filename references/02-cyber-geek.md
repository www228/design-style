# 2. 深网赛博极客风

视觉定位：强烈的科技感、未来感与极客内核。非常适合用于少儿编程、AI 创客课程的先导课，或者科技类项目路演。

## 原始风格提示词

> 风格请用深网赛博主视觉 + 全息霓虹双调：封面/章节页深邃暗夜灰黑网格底，标题用全息发光错位故障（Glitch）文字配 ◬ 霓虹发光三角 kicker；内容页用深色磨砂玻璃（Glassmorphism）底，搭荧光青绿与赛博粉点缀；漂浮全息数据流 + 蓝紫呼吸光晕；路线图用高亮印刷电路板（PCB）走线 + 微型发光芯片节点；插画用 3D 潮玩风格的极客少年（戴 VR 头显、机械手臂）和像素风电子宠物伙伴；整体参考赛博朋克 UI 界面与顶级极客桌面。
